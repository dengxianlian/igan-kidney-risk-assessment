# 肾眼智能体离线模型网页

这是一个无依赖的静态网页原型，支持三个基于逻辑回归的模型：

- IgAN-uBASE
- IgAN-BASE
- IgAN-OxT

## 本地运行

可以直接双击 `index.html` 打开，也可以在当前目录启动静态服务：

```powershell
python -m http.server 8080
```

然后访问 <http://localhost:8080>。

页面中的计算均在浏览器本地完成，不会上传输入数据。部署到 GitHub Pages 时，可以直接使用静态文件或配置 GitHub Actions 发布。

界面默认使用 English，可在右上角切换中文、Deutsch、Français、Italiano 或 日本語。三个模型的年龄输入范围统一为 0–90 岁，结果运行后才会展开风险分层、列线图和变量解释。

列线图的变量行使用建模队列观察范围建立 points 标尺；校准总分行投影到完整的 0–100% 概率轴，风险阈值对应的总分刻度与概率刻度共用同一横坐标，因此总分点与概率点始终对齐。变量解释中的 Bar 与 Scatter 按当前病例绝对贡献度从高到低使用同一顺序，并统一采用 `beta × 实际输入值` 作为有符号线性贡献；两图中的正向贡献均为红色、负向贡献均为绿色，Scatter 的当前病例点也按正负方向着色并标出与 Bar 相同的贡献值，分别落在零线右侧或左侧。Bar 与 Scatter 共享覆盖模型变量观察范围及当前病例的同一贡献幅度上限，因此每个项目的数值、符号、排序和相对比例均一致。

结果卡片中的五分类风险条也按 0/15/40/70/90/100% 的实际阈值定位标签；列线图与贡献图在窄屏下保持横向滚动，不改变页面主体宽度。

## 公式与精度核对

网页按已确认的三组逻辑回归系数计算，系数以完整十进制文本保留后再参与计算；连续检验结果不会按输入框的小数位自动舍入，年龄使用整数 0–90 岁。`formula-regression.test.mjs` 使用合成数值执行三模型回归检查，并验证 OxT 的 C3 项，不包含患者数据。可运行以下命令复核：

```powershell
node formula-regression.test.mjs
```

本轮审计使用的截图示例按正式 uBASE 公式得到 `A≈3.6710057313359323`、`P≈97.51808094%`（界面显示为 `97.52%`）。若某个 Excel 文件得到 `A=3.1722`，应优先检查该文件的单元格公式、列引用或模型版本；该结果并非上述公式的计算结果。患者或示例原始数值不写入本仓库。

> 重要：模型结果仅作临床辅助评估，不能替代医生诊断。正式临床使用前，应完成模型外部验证、适用人群确认、输入范围校验和医学伦理/合规评估。
